# Security

Report suspected vulnerabilities or credential exposure privately to
`security@intelligentiterations.com`. Do not include
service-account keys, tokens, private keys, customer data, or other secrets in
an issue, pull request, commit, build log, or chat message.

Include the affected revision, impact, reproduction steps, and a minimal
non-sensitive proof when possible. The maintainers will acknowledge a report
and coordinate remediation and disclosure through the reporting address.

Deployment credentials and environment-specific topology belong in an
operator-controlled implementation repository. This repository contains
source and inert examples only.
